# Cyber-security-awareness-notes
This is a set of cybersecurity awareness which can be used to help individuals and organisations understand key concepts.It includes information about email phishing attempts, the creation of strong passwords, safeguarding personal information and knowing how to report any issues.
## What is included
-**phishing.md**-How to identify and prevent phishing email attacks
-**passwords.md**-Setting up strong passwords and implementing the use of multi-factor authentication
-**social-media.md**-keeping personal information safe online
-**reporting.md**- what to do if one has a security isssue
## How to use
Read through each of the files to learn about a variety of topics.These can be shared with colleagues or classmates.
