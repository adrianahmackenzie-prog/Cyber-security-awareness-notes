# Setting up strong passwords and implementing the use of multi-factor authentication
- A strong password is the first line of defense that protects the online accounts,using a weak password makes it easier for malicious users to access personal information.
- Multi- factor authentication helps as the stolen password will not be of any use to the attackers as a second authentication factor will be needed which is hard to obtain.
- When creating strong passwords there should be a mix of capital letters, lower case letters and special characters.
